What is emulated?

The enhanced 1D_SOUND.ino from your fork is compiled as native C++, with adapters for Arduino time, GPIO buttons, FastLED, Preferences, Wi-Fi, and WebServer. All ten levels, three bosses, both bonus games, scoring, the three-hit shield, guided training, normalized movement, and feedback run from that source. The main-game shield carries across levels and refills on a new run; surviving hits clear boss projectiles, knock the wave back, and give one second of recovery. Bonus lives stay separate. Training is unscored; movement uses elapsed time and a 240-LED reference distance. Scene jumps bypass progression locks only when requested.

This is source-level firmware emulation, not instruction-level ESP32 emulation. CPU timing, electrical LED timing, power limiting, Wi-Fi radio, I²S DMA, and OTA flashing are not modeled. HSV colors are approximated. Audio uses the firmware’s melody data through Web Audio, with approximated queue timing. Randomness is deterministic on boot but differs from ESP32 randomness. Preferences persist in a local emulator file and never touch your board. One virtual board is shared by tabs on this local server.
